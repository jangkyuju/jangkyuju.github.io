# Security Policy

## Supported version

The website deployed from the `main` branch is the only supported version.

## Reporting a vulnerability

Please report suspected vulnerabilities privately by email to `jju39@gatech.edu`.
Do not include sensitive exploit details in a public GitHub issue. Include the affected
URL or file, reproduction steps, impact, and any suggested remediation. You can expect
an acknowledgement within seven days.

For general content corrections or non-sensitive bugs, opening a public GitHub issue is appropriate.
